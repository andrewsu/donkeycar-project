# Donkey Car project

Notes for a parent/kid self-driving RC car project built on [Donkey Car](https://docs.donkeycar.com) and its simulator.

- [`self_driving_car_project.md`](self_driving_car_project.md): an intro meant to get a kid excited about the project
- [`technical_notes.md`](technical_notes.md): technical notes and a ~2-month plan (RL in the sim, autoresearch-style optimization, the physical build)

`media/smooth.gif` and `media/level1.gif` are from Antonin Raffin's [learning-to-drive-in-5-minutes](https://github.com/araffin/learning-to-drive-in-5-minutes) (MIT License). The other images are linked from the [Donkey Car docs](https://github.com/autorope/donkeydocs) and YouTube.
